The on-disk blob basename and the fixture/provenance SHA manifests use only the 64 hex characters. On 2026-10-13 the initial bare-hex DTO expectations were corrected before implementation: an actual existing `Workspace::freeze_snapshot` with real SHA-256 on an isolated copy of this export produced byte-identical canonical manifest and SnapshotRef to independent Python computation. The original config/CAS/anchor/facts bytes were unchanged. `metadata.json.expected_wire_correction` binds the probe and records that old expected-value evidence is stale.
