# Bootstrap Join（自动入网）设计文档集

本目录收录 Nexus 子网「Bootstrap 自动入网」特性从初稿到定稿的成套文档。最终实现以 **v2 修订定稿**为准。

## 文档与关系

| 顺序 | 文件 | 说明 |
|---|---|---|
| 1 | [01-design-v1-draft.md](01-design-v1-draft.md) | v1 设计初稿：目标、线协议帧、服务端/客户端总体方案、配置示例与分阶段计划。 |
| 2 | [02-review.md](02-review.md) | 独立技术评审报告：对照真实源码逐行核实，给出可落地实现方案、7 个阻断项（S1–S7）、3 处事实更正（C1–C3）与精确代码位置。 |
| 3 | [03-design-v2-final.md](03-design-v2-final.md) | v2 修订定稿：开头 Changelog 逐条对应评审结论，给出最终模块归属、认证、VIP、半开防护、客户端装配与验证方案。 |

演进关系：**v1 初稿 → 独立评审报告 → v2 修订定稿**。v1 仅作历史留档，其中部分判断已被评审更正；实现与验收一律以 v2 为准。

## 行号基准

- v2 中 `文件:行号` 的核对基准为提交 `cda5f21`；该特性分支后 rebase 到主干 `4891886`，个别行号可能漂移，阅读时以当前工作树实际位置为准。
- 文档中的 VIP（如 `10.144.144.0/24`）、PSK、端口与文档保留地址（RFC 5737 / RFC 2544 文档网段）均为配置示例。

## 实现状态

- 已完成 P1–P4：线协议帧与确定性编解码、服务端纯逻辑（PSK 会话认证、node_id 与 static 公钥绑定、VIP 分配、在线目录、半开防护）、客户端装配（joiner 多引导故障转移、隧道 `nxb:` 分流、持久身份、前台运行守卫）、以及**真实 UDP loopback 全链路（含节点间 P2P 加密数据帧）验证通过**。
- P5 为后续工作：TUN/真机跨机与对称 NAT、relay 场景、引导节点位于 NAT 后、daemon 隧道宿主线程、半开无状态 cookie。
